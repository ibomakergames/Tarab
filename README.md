# طرب أندرويد (Tarab Android)

مشروع Android أصلي باسم **طرب أندرويد**.

## الموجود في النسخة التأسيسية
- تطبيق Android مستقل بمعرّف `com.ibomaker.tarab`.
- متصفح WebView داخلي يدعم JavaScript وDOM storage وملفات تعريف الارتباط.
- تشغيل روابط الوسائط التي تسمح بها المواقع داخل المتصفح.
- إرسال التنزيلات المباشرة التي يمررها WebView إلى Android DownloadManager مع إشعار النظام.
- GitHub Actions لبناء APK تجريبي ورفعه كـ Artifact.

## حدود هذه المرحلة
هذه ليست نسخة مكتملة أو مطابقة وظيفيًا لتطبيق iOS. تنزيل الفيديو من كل منصة، خصوصًا منصات البث المحمية أو التي تستخدم روابط مجزأة/DRM، لا يمكن ضمانه من متصفح عام. ما زالت مكتبة التنزيلات الداخلية، مشغل مستقل، تحويل الصوت والفيديو، وإدارة الملفات والميزات الإضافية بحاجة إلى تنفيذ واختبار.

## البناء
يبدأ GitHub Actions البناء عند الدفع إلى `main` أو يدويًا من تبويب Actions.
المسار المتوقع: `app/build/outputs/apk/debug/app-debug.apk`.
