# طرب أندرويد

مشروع Android مستقل باسم **طرب أندرويد**، مبني باستخدام Kotlin وAndroid SDK.

## الوظائف المنفذة في النسخة الحالية
- واجهة عربية داكنة مع تبويبات: الرئيسية، المتصفح، التنزيلات، مكتبتي، الإعدادات.
- متصفح مدمج يدعم JavaScript وDOM Storage وملفات تعريف الارتباط.
- استقبال روابط التنزيل المباشرة التي ترسلها المواقع إلى WebView، وإدارتها عبر Android DownloadManager.
- فحص عناصر HTML الظاهرة في الصفحة بحثًا عن روابط فيديو/صوت مباشرة قابلة للتنزيل.
- شاشة تنزيلات تعرض الحالة وتسمح بفتح الملف المكتمل أو حذف مهمة التنزيل.
- اختيار ملفات الصوت والفيديو من الجهاز عبر منتقي ملفات أندرويد.
- تشغيل الفيديو محليًا عبر VideoView.
- تشغيل الصوت في الخلفية عبر Foreground Service مع إشعار وأزرار تشغيل/إيقاف مؤقت/استئناف/إيقاف.
- أيقونة تطبيق مخصصة وثيم داكن.

## قيود مهمة
هذه النسخة **0.2.0 تجريبية وليست استنساخًا كاملاً لتطبيق iOS**. لا يمكن ضمان تنزيل كل منصة: الروابط المحمية بـDRM، والبث المجزأ، والمحتوى الذي تمنع شروط الموقع تنزيله لا يتحول تلقائيًا إلى ملف. فحص الصفحة يلتقط روابط الوسائط المباشرة الموجودة في DOM فقط، ولا يفك حماية أو يلتقط كل تدفقات الشبكة.

ميزات تحرير الفيديو، إزالة الصوت البشري، فصل الموسيقى عن الصوت، تحويل الصيغ، قفل الملفات، سلة المحذوفات، ومكتبة داخلية ببيانات وصفية متقدمة لم تُنفذ بعد.

## بناء APK
يبدأ GitHub Actions بناء APK تجريبيًا عند كل تحديث إلى الفرع `main` أو عند تشغيل Workflow يدويًا.
بعد نجاح البناء، نزّل Artifact باسم `Tarab-Android-debug` من صفحة Actions.

مسار APK داخل بيئة البناء:
`app/build/outputs/apk/debug/app-debug.apk`

لا يُعدّ APK جاهزًا للتثبيت قبل نجاح Workflow وتجربته على جهاز أندرويد فعلي.
